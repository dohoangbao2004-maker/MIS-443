## 📌 Project Overview

This repository contains my Banking Database project developed as part of **MIS443 – Database Management**.

The project focuses on building a complete relational database from scratch using PostgreSQL. It includes database creation, table design, relationship modeling, CSV data import, and SQL query development to solve a variety of real-world business scenarios.

Rather than simply answering SQL exercises, this project demonstrates my understanding of relational databases and my ability to transform business requirements into structured SQL solutions.

---

## 🎯 Objectives

The main objectives of this project are to:

- Design a relational banking database
- Implement relationships using Primary Keys and Foreign Keys
- Import structured CSV datasets into PostgreSQL
- Write SQL queries to solve business problems
- Practice analytical SQL using PostgreSQL

## 🗂 Database Structure

The Banking database consists of five related tables:

```text
branches
│
├── customers
│      │
│      ├── accounts
│      │       │
│      │       └── transactions
│      │
│      └── loans
```

The relationships are implemented using Primary Keys and Foreign Keys to maintain data integrity.
